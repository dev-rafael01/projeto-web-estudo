# Projeto Web Services

Projeto Web Services é uma aplicação web **Back-end**, desenvolvida como treinamento sobre o framework **Spring Boot**, utilizando **JPA/Hibernate**, com base no curso da [DevSuperior](https://devsuperior.com "DevSuperior"), disponível como curso livre na plataforma Udemy.

A aplicação consiste no treinamento de criação de um sistema organizado em camadas, estruturado em **Config, Entities, Enums, Repositories, Services e Resources**.

### Fluxo básico

**Cliente → Resources → Services → Repositories → Banco de Dados**

### Caminho de volta

**Banco de Dados → Repositories → Services → Resources → Cliente**

## Estrutura em camadas

* **Config:** configurações da aplicação.
* **Entities:** representação dos dados e das entidades do sistema.
* **Enums:** valores e opções predefinidos.
* **Repositories:** acesso e persistência dos dados no banco de dados.
* **Services:** regras de negócio e lógica da aplicação.
* **Resources:** endpoints e comunicação com as requisições HTTP.
